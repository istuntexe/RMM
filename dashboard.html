The executable is unsigned. Each download contains one private device credential. Use a fresh download for each computer.

Connect a computer

  1. Download and extract the ZIP on the Windows computer you want to monitor.
  2. Open PowerShell as Administrator in the extracted folder and run powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1.
  3. Read the collection notice and type INSTALL to authorize the visible Windows service.
  4. The device replaces its pending entry and reports every minute, including after reboot.

Use the included uninstaller to remove the service. Revoke its credential here if the computer is retired.
